# LordSerials Plugin для Lampa

Плагин для поиска и просмотра сериалов с сайта **lordserials.fan** в приложении Lampa.

## Возможности

- Поиск сериалов по названию с debounce
- Открытие карточки сериала и списка эпизодов
- Выбор сезона и фильтрация эпизодов
- Запуск эпизода через `Lampa.Player.play`
- Обработка ошибок сети и fallback уведомления

## Установка

### Способ 1: Через URL (рекомендуется)

1. Откройте приложение Lampa
2. Перейдите в **Настройки → Расширения**
3. Выберите **"Добавить плагин"**
4. Укажите URL:
   ```
   https://raw.githubusercontent.com/YOUR_USERNAME/YOUR_REPO/master/main.js
   ```
5. Нажмите **"Добавить"**

### Способ 2: Локальная разработка

1. Скопируйте файл `main.js` в директорию плагинов Lampa
2. Или используйте локальный веб-сервер:
   ```bash
   # В директории проекта
   python -m http.server 8000
   ```
3. В Lampa укажите URL: `http://YOUR_IP:8000/main.js`

## Использование

1. После установки в главном меню появится пункт **"LordSerials"**
2. Выберите его и введите название сериала в поле поиска
3. Нажмите **"Найти"** или Enter
4. Выберите сериал из результатов поиска
5. Нажмите **"Смотреть"** для запуска первой серии или выберите конкретную серию из списка

## Технические детали

### API Lampa

Плагин использует следующие модули Lampa API:

- `Lampa.Component` - регистрация компонентов
- `Lampa.Template` - HTML-шаблоны
- `Lampa.Activity` - управление экранами
- `Lampa.Controller` - навигация
- `Lampa.Player` - воспроизведение видео
- `Lampa.Listener` - подписка на события
- `Lampa.Noty` - уведомления
- `Lampa.Select` - списки выбора

### Поиск

Поиск работает через стандартный механизм поиска сайта:
```
https://lordserials.fan/index.php?do=search&subaction=search&story={query}
```

## Известные ограничения

1. **Доступность сайта**: lordserials.fan может быть недоступен в некоторых регионах
2. **CORS/защита сайта**: в некоторых окружениях браузер может блокировать прямые запросы
3. **Плеер**: Сайт может использовать различные плееры, не все из которых совместимы

## Быстрая проверка

1. Откройте `test.html` в браузере.
2. Нажмите "Перезагрузить плагин" и убедитесь, что в логах есть регистрация компонентов.
3. Нажмите кнопку `LordSerials` и проверьте открытие экрана поиска.
4. Введите запрос и проверьте состояния:
   - результаты найдены;
   - пустой результат;
   - ошибка сети (например, отключите интернет).
